QuantumSec Content Bot

Automatización de la planificación editorial semanal con Python y GitHub Actions

Completado

Cada semana recopila noticias de ciberseguridad, las filtra por relevancia y publica un calendario editorial visual con una propuesta de contenido para cada día.

Recogida y filtrado

Python con fuentes RSS, la API de Hacker News y Reddit, filtro de relevancia por palabras clave y traducción automática de los resúmenes.

Publicación automática

GitHub Actions ejecuta el bot cada semana, genera el calendario en JSON y lo publica en GitHub Pages con formato por día (reel, carrusel o post).
