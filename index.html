Proyectos

Proyecto completado

Tienda online — Shopify + Supabase

E-commerce con backend propio y diseño construido desde cero, sin plantillas.
Frontend & gestión de estado

React (Vite) — framework principal para construir una interfaz rápida y reactiva, con arquitectura modular basada en componentes funcionales.

React Context API — sistema de estado global (CartContext) para controlar el carrito de compra: añadir productos, actualizar cantidades de forma dinámica, vaciar ítems y sincronizar los totales en euros entre rutas y componentes, sin prop-drilling.

E-commerce & pasarela de pago

Shopify Storefront API (GraphQL) — conexión del frontend con el motor de Shopify mediante consultas y mutaciones optimizadas.

Shopify Cart API & Checkout — servicio intermedio propio (shopifyCheckout) que transforma y mapea los IDs de productos de la base de datos local a variantes globales de la API (gid://shopify/ProductVariant/), logrando la redirección a la pasarela segura de pago.

Backend & persistencia

Supabase — usado como BaaS para la gestión y almacenamiento del catálogo de productos y usuarios, con persistencia en una base de datos relacional PostgreSQL.

Control de versiones & DevOps

Git & GitHub — gestión del historial de ramas, resolución de conflictos de combinación (estrategia --ours), sincronización local-remota y despliegue desde GitHub Codespaces a entornos locales.

Visual Studio Code — IDE principal, con control de versiones integrado y terminal avanzada (PowerShell/Bash) para automatizar comandos de Git.

  • React
  • Vite
  • Context API
  • Shopify GraphQL
  • Supabase
  • PostgreSQL
  • Git/GitHub
En desarrollo

Salpicados — plataformas con minas de agua

Mario Bros por fuera, Buscaminas por dentro: cada partida genera un mapa distinto.
Core stack & motor de juego

JavaScript (ES6+) — lenguaje principal para toda la lógica del juego, el control de flujo, la gestión de eventos del usuario y la manipulación dinámica de elementos.

Phaser 3 — framework de código abierto para videojuegos 2D en HTML5, elegido por su sistema de renderizado, su gestión del ciclo de vida (preload, create, update) y su escalabilidad.

Arquitectura & sistemas del juego

Phaser Arcade Physics — motor de físicas integrado para gestionar gravedad, hitboxes, velocidades y fricción de los personajes sobre las plataformas, optimizado a 60 FPS.

Cámaras y viewport dinámico — sistema de seguimiento de cámara (startFollow) y scroll lateral que renderiza un mundo extendido más allá de los límites de la pantalla inicial.

Metodologías de programación

Generación procedural y algoritmia — creación dinámica del mapa mediante bucles lógicos y cálculo de probabilidades (Math.random()) para posicionar las minas de agua, haciendo que cada partida sea única.

Programación orientada a eventos — gestión del flujo de pantallas (inicio → selección de personaje → partida activa) con listeners de Phaser para clics, pantallas táctiles y teclado en tiempo real.

Entorno de desarrollo & despliegue

GitHub Codespaces — entorno de desarrollo en la nube basado en contenedores Docker, para un workspace consistente y accesible desde cualquier dispositivo.

Node.js & Serve — servidor local de desarrollo con recarga en vivo (Live Reloading), optimizando el ciclo de pruebas y depuración en el navegador.

  • JavaScript
  • Phaser 3
  • Arcade Physics
  • Generación procedural
  • GitHub Codespaces
  • Node.js
Prácticas en curso

QuantumSec — producción de contenido en ciberseguridad con IA

Pipeline completo de contenido para Instagram y LinkedIn: dev, motion design e IA.

Animación y motion graphics

Remotion (React + TypeScript) — generación de vídeos verticales con composiciones declarativas, animaciones SVG, efectos de partículas y transiciones programáticas, sobre un design system de marca con varias paletas visuales (cyberpunk/Matrix, minimalista, corporativo).

Transcripción y subtitulado

Faster-Whisper (CTranslate2) — transcripción automática de audio con timestamps a nivel de palabra, generación de subtítulos sincronizados y exportación a formato SRT.

Síntesis de voz

ElevenLabs y Chatterbox-Turbo — integración y evaluación de locuciones y voces sintéticas para el contenido generado.

Investigación de contenido

Last30days — research agéntico para identificar tendencias y noticias de ciberseguridad en tiempo real, alimentando el calendario editorial.

Desarrollo asistido por IA

Claude Code — copiloto de desarrollo para iterar sobre componentes React/TSX, depurar pipelines de render y resolver incompatibilidades de entorno (versiones de Node con NVM, configuración de FFmpeg, conflictos de dependencias).

Edición de vídeo

FFmpeg — procesamiento, escalado y conversión de vídeo, con herramientas como Editor Pro Max como referencia de UX para flujos de edición asistidos por IA.

Responsabilidades
